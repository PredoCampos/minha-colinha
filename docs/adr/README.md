# Architecture Decision Records (ADRs)

ADRs registram decisões estruturais cujo motivo pode não ser óbvio no futuro. Não devem ser usados para detalhes triviais de implementação.

## Formato

Cada ADR contém:

- Status;
- Contexto;
- Decisão;
- Alternativas consideradas;
- Consequências.
